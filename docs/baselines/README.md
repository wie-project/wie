# Baselines — WIE_RUNTIME_PROFILE captures

Paired captures for `WIE_IDLE=park` vs `WIE_IDLE=yield` (perf-plan Phase 0 + Wave 3).

- Generated by `scripts/capture-baseline.sh` (see `docs/perf-plan.md` Phase 0 and `docs/perf-plan-2.md` Wave 3).
- Each run: `cargo build -p wie-cli --release` then `WIE_RUNTIME_PROFILE=1 WIE_IDLE=<park|yield> wie run <exe>` for exactly 40 s, stopped with **SIGINT** (the pump drains `take_ctrlc_for_profile_stop()` and prints `=== WIE_RUNTIME_PROFILE ===` on stderr — see `crates/wie-winapi/src/console/host_term.rs` and `crates/wie-cli/src/commands/run.rs`).
- Files:
  - `park.txt` / `park.json` — park capture (stdout+stderr)
  - `yield.txt` / `yield.json` — yield capture (stdout+stderr)
  - Legacy single-label captures: `<label>.txt` / `<label>.json`
- Verification: each file must contain `idle_residency_ms` / `emu_ms` / `wall_ms` and `=== WIE_RUNTIME_PROFILE ===`; otherwise the SIGINT→profile handoff is flaky.
- Diff: the script runs a python3 summary printing wall/CPU%, `bg_stall_us`/`bg_to`/`bg_enq`, iced share (`iced` / `jit_insns+iced`), and `idle_residency_ms` delta.

Default exe: `micro-exes/out/long_loop.exe` (built via `make -C micro-exes` if missing).

Idempotent: re-running the script overwrites the baseline files; `.gitkeep` keeps the directory tracked when captures are skipped.
