# S2 — background-compile stall elimination

## Scope
`crates/wie-cpu/src/jit/config.rs`, `crates/wie-cpu/src/jit/pipeline.rs`

## Baseline (release)
- bg_stalls=1424, bg_stall_us=1,834,410 (~1.8s critical path)
- compiles=38 inline + 7249 bg_enq; bg_hit=1388; bg_to=36; bg_fallback=36
- never=144 blocks never compiled (iced fallback 4.74M insns)

## Tasks
1. Log per-RIP stall reasons: add [STALL] counter at bg_stall increments
   recording the entry_rip that triggered the wait.
2. Top stall sites → pre-warm: enqueue those blocks for background compile
   earlier (lower effective hotness or explicit predecessor-chain pre-warm).
3. Audit `never=144`: identify which instructions keep blocks in iced and
   whether they can be supported.
4. Dedupe: compiles=38 but bg_compiles=7249 — check if the same RIP is
   enqueued multiple times.

## Exit criteria
bg_stall_us < 400ms in release profile. cargo test green.
