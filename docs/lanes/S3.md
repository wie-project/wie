# S3 — dispatcher fixed-cost reduction

## Scope
`crates/wie-cpu/src/jit/pipeline.rs` (run_compiled entry/exit)

## Baseline (release)
- host_stops=74142 (noisy=32488) API dispatch stops
- emu_ms=39.8s wall, handler_ms=180ms — emulation dominates
- jit insns=735M; iced=4.74M residual
- Per-run: pin refresh check, JitCtx build (16 GPR + 16 XMM snapshot),
  native call, full writeback (16 GPR + 16 XMM), stats, TLB/sticky persist

## Tasks
1. Microbenchmark per-run fixed cost: time N empty-body runs to isolate
   dispatch overhead from actual execution.
2. Trim provably redundant work:
   - ctx field init: only initialize fields the block actually reads
   - stats accumulation: gate behind profile_enabled
   - TLB/sticky persistence: skip when no memory op executed
3. host_stops analysis: categorize by resolved export name to find
   high-frequency/low-value stops that could be batched or inlined.

## Exit criteria
Measured per-run cost reduction OR documented proof current cost is
negligible. cargo test green.
